# OMCRE8 Studio

Official website and digital portfolio for OMCRE8 Studio — craft-focused digital design, web applications, and branding.

## Tech Stack

- **Framework**: TanStack Start (Fullstack React with SSR)
- **UI & Styling**: React 19, Tailwind CSS v4, Radix UI Primitives, Lucide Icons
- **Language**: TypeScript
- **Database / Backend**: Supabase
- **Build Tool**: Vite

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm or bun

### Local Development

1. Install dependencies:
   ```sh
   npm install
   ```

2. Start the development server:
   ```sh
   npm run dev
   ```

3. Open [http://localhost:8080](http://localhost:8080) (or the port specified in console output) to view the site.

### Build & Production

```sh
# Type check and build production bundle
npm run build

# Preview production build locally
npm run preview
```
