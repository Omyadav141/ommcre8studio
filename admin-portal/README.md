# OMCRE8 Studio — Admin Command Center

Secure leadership and operations portal for **OMCRE8 Studio (Om Create Studio)**, founded by **Om Yadav** ([omyadav.online](https://www.omyadav.online/)).

---

## Features

- **Lead & CRM Management**: Full intake CRM pipeline (`New` &rarr; `In Review` &rarr; `Proposal Sent` &rarr; `Discovery Booked` &rarr; `Won & Started` &rarr; `Archived`). Search by client name, email, company, and reference.
- **Inquiry Detail Drawer**: Inspect client project briefs, budget, timeline, and write persistent internal admin notes.
- **Direct Email Templates**: One-click replies for scheduling discovery calls, sending scope proposals, and kickoff updates.
- **Discovery Appointments**: View scheduled video calls synced via Calendly (`https://calendly.com/omyadv`) and Google Meet.
- **Public AI Assistant Logs**: Monitor what visitors are asking the Cre8 Studio AI on the public site and observe lead signals.
- **Portfolio & Case Studies CMS**: Manage publication status and hero featured placement for flagship work (e.g. True Legal Advice `trulegaladvice.com`).
- **Integration Health**: Live status checks for Calendly, Resend / SMTP email dispatch, Supabase / SQLite database, and AI engine.
